# Удирдлагын самбар (admin dashboard)

`/admin` — ажилтнууд нэвтэрч сайтын хүсэлт, контент, файлыг удирдана.

| Хэсэг | Юу хийх | Эрх |
|---|---|---|
| Тойм | Шинэ / хийгдэж буй хүсэлтийн тоо, сүүлийн хүсэлтүүд | Бүгд |
| Хүсэлтүүд | “Холбоо барих”, “Үнэгүй хэмжилт” маягтын хүсэлт: хайх, шүүх, төлөв, хариуцагч, тэмдэглэл, CSV | Бүгд (устгах — Админ) |
| Контент | Удирдлага, Үйлчилгээ, Түгээмэл асуулт (MN + EN): засах, нэмэх, дараалал, нуух | Бүгд |
| Файл & зураг | JPG/PNG/WebP/PDF оруулах (15 MB хүртэл), холбоос хуулах, устгах | Бүгд |
| Тохиргоо | Утас, и-мэйл, хаяг, газрын зураг, танилцуулга PDF | Бүгд |
| Мэдээ | Нийтлэл бичих (MN заавал, EN сонголттой), нүүр зураг, ноорог / нийтлэх / товлох | Бүгд |
| Ажлын анкет | Ажлын байр зарлах; ирсэн анкет, CV татах, төлөв (Шинэ → Ярилцлага → Ажилд авсан) | Бүгд (устгах — Админ) |
| Санал асуулга | Асуулт зохиох (5 төрөл), холбоос хуваалцах, үр дүн, CSV | Бүгд (устгах — Админ) |
| Хэрэглэгчид | Нэмэх, эрх (Админ / Редактор), идэвхгүй болгох, нууц үг солих | Админ |

Хадгалмагц сайтын хуудсууд (MN + EN) шууд шинэчлэгдэнэ.

## Server дээр суулгах (VPS, `next start`)

1. PostgreSQL дээр тусдаа database, хэрэглэгч үүсгэнэ.
2. `.env.example`-ийг `.env.local` (эсвэл systemd орчны хувьсагч) болгон бөглөнө. `UPLOAD_DIR`, `PRIVATE_UPLOAD_DIR` (CV) нь апп-ын хавтаснаас гадуур, backup-д орсон хавтас байна. `PRIVATE_UPLOAD_DIR`-ийг nginx-ээр хэзээ ч нийтэд нээхгүй.
3. Суулгах:
   ```bash
   npm ci
   npm run db:deploy   # migration
   npm run db:seed     # одоогийн контент + анхны админ (хэрэглэгч байхгүй үед л)
   npm run build
   npm start           # эсвэл pm2 / systemd
   ```
4. Анх нэвтэрсний дараа “Миний бүртгэл” хэсэгт нууц үгээ сольж, `ADMIN_PASSWORD`-ийг орчноос устгана.
5. nginx: `proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;` (хүсэлтийн хязгаарлалт IP-гаар ажиллана), HTTPS заавал.
6. Backup: PostgreSQL dump + `UPLOAD_DIR` + `PRIVATE_UPLOAD_DIR` хавтас.

## Аюулгүй байдал

- Нууц үг bcrypt (12), сешн нь httpOnly cookie, DB-д зөвхөн token-ы hash хадгална, 7 хоног хүчинтэй.
- Нэвтрэх оролдлого: IP + и-мэйл тутам 10 минутад 5. Маягт: IP тутам 10 минутад 5, бот барих далд талбар.
- Файл: агуулгаар нь шалгана (SVG хориотой), зөвхөн бүртгэлтэй файл `/media/...`-аар үйлчилнэ.
- `/admin` хайлтын системд индекслэгдэхгүй, iframe-д ачаалагдахгүй.
